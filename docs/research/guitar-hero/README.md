# Guitar Hero research for MIDI-HERO

Research prepared September 27, 2026, to guide a game where enjoyable play motivates people to learn songs on a real keyboard. The starting brief is deliberately simplified arrangements within two octaves, with room to expand. The analysis is independent of MIDI-HERO's current implementation.

Start with the [north-star report](MIDI-HERO-NORTH-STAR.md). It connects observed mechanics and documented design decisions to proposed principles, feedback rules, arrangement progression and validation work.

## Evidence and status

The package includes sampled gameplay frames, original manuals and developer accounts, commit-pinned technical sources, chart comparisons and learning research. It distinguishes documented behavior, observation, inference and proposed design choices. Modern recreations, mods and teaching examples are not treated as original Guitar Hero source code.

**Audio feasibility pilot attempted; listening remains outstanding.** Existing video pages are accessible, but original audio, an interpretable auditory error/recovery sequence and reproducible source-file analysis have not passed the pilot gates. No new game behavior was heard or measured. See the [pilot findings](audio-pilot-findings.md) and [capture/listener handoff](audio-pilot-handoff.md). The [audio assessment plan](audio-assessment-plan.md) remains the prospective protocol. A separate [student trial protocol](student-audio-trial.md) can test provisional keyboard recommendations sooner without claiming that the Guitar Hero study is complete.
