# Classroom hardware test (about 20 minutes)

For the owner, on real hardware, before students use a build. Covers item 6 of the gameplay
checklist and the Chromebook question for the perspective highway. Tick each box; write down
anything that fails and the song, level and setting it failed on.

Open the site (the Pages URL once Pages is on, or `npm run dev` → `http://localhost:5173`) in
Chrome. Plug the keyboard in **before** loading the page.

## 1. Oxygen 25 on a Mac or PC (8 min)

- [ ] First run: the keyboard is found; "Press the lowest C on your keyboard" lines the window
      up with the octave buttons. Press an octave button and repeat: it still lines up.
- [ ] Settings → Keyboard size 25, Sound of my notes "the song's part when I play it right".
- [ ] Settings → calibrate timing: tap the 8 clicks, then the visual test. Note both numbers:
      input ____ ms, visual ____ ms.
- [ ] Ode to Joy, **Easy**: right notes sound the melody, a wrong key clunks, a missed note is
      silent. Streak counter grows and breaks; multiplier meter fills.
- [ ] Hold a long note: the trail lights and the hold bar fills. Let go early: trail goes grey.
- [ ] Gold (star) phrase played clean, then **sustain pedal** down: "STAR POWER!", gold
      highway, doubled multiplier. (Space does the same without a pedal.)
- [ ] Miss on purpose for a while: the meter drops, the highway dims, drums and pads drop out.
- [ ] Results: percentage counts up, stars appear, one suggestion for what to do next.
- [ ] Ode to Joy, **Medium**: hold a key past its note: bonk, red key, a small cost.

## 2. Yamaha with its own speakers (4 min)

- [ ] Settings → Sound of my notes "none", and Local Control **on** at the keyboard: you hear
      only the keyboard, once, with no doubled sound.
- [ ] Or leave Local Control off with "the song's part…": the game sounds your part.
- [ ] Settings → Keyboard size 61/88: the whole part shows without folding.

## 3. School Chromebook (6 min)

- [ ] Wired headphones or speakers. Settings shows audio latency under 60 ms.
- [ ] Minuet in G, Medium, **Flat** highway: smooth, no stutter.
- [ ] Same with Highway **Perspective**: smooth, and each falling note is clearly over its key,
      even at the top of the highway. If yes, perspective can become the default.
- [ ] If it stutters: turn off "Hit effects" and note whether that fixes it.

## 4. Class pack (2 min)

- [ ] Export class pack from the song list, import it on a second machine (or a private
      window): same songs, parts and levels.

Found a problem? Note the song, level, keyboard, browser, and what you saw vs expected, and
hand it to the next session.
