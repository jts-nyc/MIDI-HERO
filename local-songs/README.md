# Your own songs

Drop `.mid` files here and they appear in the song list when you run `npm run dev`.
This folder is gitignored and is never built or deployed, so it is the place for MIDI files
you found for your own use (pop songs, arrangements you don't have rights to share).
The file name becomes the title: `blinding-lights.mid` shows as "blinding lights".

To give songs to students, import them on each machine (drag the file onto the page) or
put them in a class pack with **Export class pack**.
